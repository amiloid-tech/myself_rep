# TgAutoProxy

Простая трэй-приложуха для Windows, которая автоматически ищет рабочий бесплатный MTProto-прокси для Telegram и открывает 	g://proxy ссылку.

## Сборка

`ash
go mod tidy
go build -ldflags="-H=windowsgui -s -w" -o TgAutoProxy.exe .
`

## Как использовать

1. Запусти TgAutoProxy.exe
2. Приложение само найдёт рабочий прокси и откроет Telegram
3. Нажми \"Добавить\" в предложении Telegram
4. Иконка в трее: можно найти новый прокси, включить автозапуск, подключить заново
